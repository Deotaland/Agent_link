# Offline pinyin dictionary

`../pinyin.tsv` is generated by `firmware/tools/generate_paper_ime.py`.
It contains the 6,763 GB2312 Hanzi supported by the shipped raster font, their
readings, single-character frequency rankings and a small firmware-authored
phrase list. It is a deterministic character-candidate IME, not a learned
sentence predictor. Single-character candidates remain available beyond page one.

Sources:

- [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data), MIT, copyright
  2016 mozillazg. See `pinyin-LICENSE.txt`.
- [fxsjy/jieba](https://github.com/fxsjy/jieba), MIT, copyright 2013 Sun Junyi.
  Only its single-character frequency numbers are used. See `jieba-LICENSE.txt`.

The corresponding `*-source.json` files record the upstream URLs and SHA256
checksums of the exact input files. The generator verifies these hashes before
writing the table. `firmware/tools/generate_paper_resources.py` packs this table
and the shared raster font into `../paper_resources.bin`. Upstream files are cached under the ignored
`firmware/.cache/paper4-ime-sources/`; normal firmware builds need no downloads
and input conversion needs no network. The full upstream license texts are
preserved beside this notice. Message transmission still uses Agent Link.
